# myGlossa: Εγκατάσταση

Περιβάλλον προγραμματισμού ΓΛΩΣΣΑΣ για τους μαθητές του Γενικού Λυκείου. Δεν χρειάζεται καμία άλλη εγκατάσταση (Python, Java κ.λπ.): ο διερμηνευτής της ΓΛΩΣΣΑΣ είναι ενσωματωμένος.

**Λήψη:** από τη σελίδα [Releases](https://github.com/pliroforikos/myGlossa-releases/releases/latest) διάλεξε το αρχείο που ταιριάζει στον υπολογιστή σου:

| Αρχείο | Για | Πότε το προτιμάς |
|---|---|---|
| `myGlossa-<έκδοση>-setup.exe` | Windows 10 / 11 (64-bit) | **Προτείνεται.** Κανονική εγκατάσταση, με συντομεύσεις και άνοιγμα των `.glo` με διπλό κλικ. Χρειάζεται δικαιώματα διαχειριστή. |
| `myGlossa-<έκδοση>-portable.exe` | Windows 10 / 11 (64-bit) | Χωρίς εγκατάσταση: τρέχει από οποιονδήποτε φάκελο ή από USB. |
| `myglossa_<έκδοση>_amd64.deb` | Ubuntu, Linux Mint, Debian (64-bit) | **Προτείνεται για Linux.** Εγκατάσταση με εικονίδιο στο μενού εφαρμογών. |
| `myGlossa-<έκδοση>-linux-x64.tar.gz` | Οποιαδήποτε διανομή Linux (64-bit) | Χωρίς εγκατάσταση: αποσυμπίεση και εκτέλεση. |

## Ενημερώσεις

Η εφαρμογή ελέγχει μόνη της, λίγο μετά την εκκίνηση, αν υπάρχει νεότερη έκδοση στο [github.com/pliroforikos/myGlossa-releases](https://github.com/pliroforikos/myGlossa-releases/releases) (χρειάζεται internet· αν δεν υπάρχει, δεν γίνεται τίποτα). Όταν υπάρχει, εμφανίζεται μια μπάρα κάτω από τα κουμπιά:

- **Εγκατεστημένη έκδοση Windows (`setup.exe`):** το κουμπί **Ενημέρωση τώρα** κατεβάζει τη νέα έκδοση και μετά το **Επανεκκίνηση και εγκατάσταση** την εγκαθιστά και ανοίγει ξανά την εφαρμογή, χωρίς να χρειάζεται να κατεβάσεις κάτι με το χέρι. Πριν κλείσει, ρωτά για μη αποθηκευμένα αρχεία. Επειδή η εγκατάσταση είναι για όλους τους χρήστες, τα Windows θα ζητήσουν δικαιώματα διαχειριστή.
- **Φορητή έκδοση και Linux:** το κουμπί ανοίγει τη σελίδα λήψης (αυτές οι εκδόσεις δεν μπορούν να ενημερωθούν αυτόματα).
- Ο έλεγχος μπορεί να γίνει και χειροκίνητα από **Βοήθεια → Έλεγχος για ενημέρωση…**, και να απενεργοποιηθεί από τις **Ρυθμίσεις**.
- Οι εκδόσεις πριν από αυτή που έχει τις ενημερώσεις πρέπει να αναβαθμιστούν μία φορά με το χέρι.

## Windows

### Εγκατάσταση (setup.exe)
1. Κατέβασε το `myGlossa-<έκδοση>-setup.exe` και άνοιξέ το.
2. Αν εμφανιστεί το μήνυμα **«Τα Windows προστάτευσαν τον υπολογιστή σας»** (SmartScreen), πάτα **Περισσότερες πληροφορίες → Εκτέλεση οπωσδήποτε**. Το μήνυμα εμφανίζεται επειδή το πρόγραμμα δεν έχει εμπορική ψηφιακή υπογραφή.
3. Διάλεξε φάκελο εγκατάστασης (ή κράτα τον προτεινόμενο) και πάτα **Εγκατάσταση**.
4. Η εφαρμογή ανοίγει από το μενού Έναρξη ή από τη συντόμευση **myGlossa** στην επιφάνεια εργασίας. Τα αρχεία `.glo` / `.gls` ανοίγουν με διπλό κλικ.

Τα προγράμματα αποθηκεύονται από προεπιλογή στον φάκελο **Έγγραφα\Glossa**.

**Σιωπηλή εγκατάσταση** (π.χ. σε όλο το εργαστήριο, από γραμμή εντολών ως διαχειριστής):
```
myGlossa-<έκδοση>-setup.exe /S
```

**Απεγκατάσταση:** Ρυθμίσεις → Εφαρμογές → myGlossa → Κατάργηση εγκατάστασης.

### Φορητή έκδοση (portable.exe)
Κατέβασε το `myGlossa-<έκδοση>-portable.exe` και άνοιξέ το. Δεν εγκαθίσταται τίποτα. Οι ρυθμίσεις αποθηκεύονται στο `%APPDATA%\myGlossa`. Για την προειδοποίηση SmartScreen ισχύει ό,τι και παραπάνω.

## Linux

### Πακέτο .deb (Ubuntu, Linux Mint, Debian)
```
sudo apt install ./myglossa_<έκδοση>_amd64.deb
```
Η εφαρμογή εμφανίζεται στο μενού εφαρμογών ως **myGlossa** και ανοίγει και από τερματικό με την εντολή `myglossa`.

**Απεγκατάσταση:** `sudo apt remove myglossa`

### Φορητή έκδοση (.tar.gz)
```
tar xzf myGlossa-<έκδοση>-linux-x64.tar.gz
cd myGlossa-<έκδοση>-linux-x64
./myglossa.sh
```
Σε διανομές που περιορίζουν τα user namespaces (π.χ. Ubuntu 24.04), το `myglossa.sh` ξεκινά την εφαρμογή χωρίς το sandbox του Chromium. Για πλήρη ενσωμάτωση προτίμησε το `.deb`.

## Αναβάθμιση από το myGlossomatheia 1.0.1

Έως την 1.0.1 η εφαρμογή λεγόταν **myGlossomatheia**.
- **Windows (setup.exe):** εγκατέστησε κανονικά τη νέα έκδοση. Η παλιά απεγκαθίσταται αυτόματα και οι συντομεύσεις γίνονται **myGlossa**.
- **Linux (.deb):** το `sudo apt install ./myglossa_<έκδοση>_amd64.deb` αντικαθιστά αυτόματα το πακέτο `myglossomatheia`.
- **Ρυθμίσεις:** στην πρώτη εκκίνηση μεταφέρονται αυτόματα από την παλιά εγκατάσταση: ανοιχτά και πρόσφατα αρχεία, εμφάνιση, αρχεία δεδομένων και η ταυτότητα καθηγητή της «Τάξης».
- **Τάξη:** το `classroom.json` που υπάρχει ήδη συνεχίζει να ισχύει. Ο installer των Windows το μεταφέρει στον νέο φάκελο. Η «Τάξη» συνεργάζεται και με υπολογιστές που έχουν ακόμα την 1.0.1, οπότε η αναβάθμιση του εργαστηρίου μπορεί να γίνει σταδιακά.

## Λειτουργία «Τάξη»

Στο εργαστήριο, ο καθηγητής βλέπει από τον υπολογιστή του **ζωντανά τον κώδικα** κάθε μαθητή και ποιος **«σηκώνει χέρι» ✋** (F9). Μπορεί επίσης να **παρουσιάσει** τον δικό του κώδικα σε όλους. Όλα γίνονται στο τοπικό δίκτυο του σχολείου, κρυπτογραφημένα (TLS), χωρίς internet, λογαριασμούς ή server.

Πρώτα στήνεται ο υπολογιστής του **καθηγητή**, γιατί από εκεί βγαίνει το `classroom.json` που χρειάζονται οι μαθητές. Όλοι οι υπολογιστές πρέπει να είναι στο ίδιο τοπικό δίκτυο. Ο καθηγητής **δεν** χρειάζεται στατική IP: οι μαθητές τον βρίσκουν μόνοι τους.

Θύρες: **TCP 47820** (σύνδεση) και **UDP 47821** (ανακάλυψη), διαφορετικές από του myPython2 και του EduPython3, ώστε οι εφαρμογές να συνυπάρχουν.

### 1. Υπολογιστής καθηγητή
1. Εγκατάσταση με το `setup.exe` (Windows) ή το `.deb` (Linux). Στα Windows ο installer βάζει αυτόματα τον κανόνα στο Τείχος προστασίας. Στο Linux, αν είναι ενεργό το `ufw`:
   ```
   sudo ufw allow 47820/tcp && sudo ufw allow 47821/udp
   ```
2. Στην εφαρμογή: **Τάξη → Λειτουργία καθηγητή…** → όνομα και εργαστήριο → **Έναρξη τάξης**.
3. **Εξαγωγή classroom.json…**, π.χ. σε USB.

> Μη βάλεις το `classroom.json` στον υπολογιστή του καθηγητή **πριν** από την εξαγωγή: σε υπολογιστή με `classroom.json` χωρίς το δικό του κλειδί, η «Λειτουργία καθηγητή» δεν εμφανίζεται.

### 2. Υπολογιστές μαθητών
Το `classroom.json` μπαίνει σε φάκελο όπου οι μαθητές **μπορούν μόνο να διαβάζουν**. Έτσι συνδέονται **μόνο** στον υπολογιστή του καθηγητή τους.

**Windows, νέα εγκατάσταση** (γραμμή εντολών ως διαχειριστής):
```
myGlossa-<έκδοση>-setup.exe /S /CLASSROOM=E:\classroom.json
```
Ο installer αντιγράφει το αρχείο στο `C:\ProgramData\myGlossa\` και κλειδώνει τον φάκελο. Η διαδρομή μπορεί να είναι και κοινόχρηστος φάκελος, π.χ. `\\server\share\classroom.json`.

**Windows, εφαρμογή ήδη εγκατεστημένη ή portable** (PowerShell ως διαχειριστής):
```
New-Item -ItemType Directory -Force C:\ProgramData\myGlossa
Copy-Item E:\classroom.json C:\ProgramData\myGlossa\classroom.json
icacls C:\ProgramData\myGlossa /inheritance:r /grant:r "*S-1-5-32-544:(OI)(CI)F" "*S-1-5-18:(OI)(CI)F" "*S-1-5-32-545:(OI)(CI)RX"
```

**Linux:**
```
sudo mkdir -p /etc/myglossa
sudo cp /media/usb/classroom.json /etc/myglossa/classroom.json
sudo chmod 644 /etc/myglossa/classroom.json
```

### 3. Στην ώρα του μαθήματος
1. Ο καθηγητής: **Τάξη → Λειτουργία καθηγητή… → Έναρξη τάξης**. Η οθόνη δείχνει ένα **PIN** 4 ψηφίων.
2. Οι μαθητές: **Τάξη → Σύνδεση στην τάξη…**, γράφουν το όνομά τους και το PIN.
3. Ο μαθητής βλέπει πάντα κάτω δεξιά ότι είναι συνδεδεμένος και αποσυνδέεται με ένα κλικ. Στον υπολογιστή του καθηγητή δεν αποθηκεύεται κώδικας μαθητών.
